# Logos

- `logo-lecres.png` : écusson du club (pastilles Le Crès).
- `filigrane-renard.png` : tête de renard seule, bords fondus (filigrane plein fond ~7 %).
- Logos adverses : un PNG par club, référencé dans `clubs.json` :
  `{"fichier": "...png", "nom": "NOM OFFICIEL", "alias": ["noms courts", "sans accents"]}`.
  Les alias de 4 lettres ou moins doivent correspondre à un mot entier du nom saisi.

Pour ajouter un club : déposer son logo (PNG transparent ou JPEG fond blanc, détouré
automatiquement), ajouter son entrée dans `clubs.json`, puis repackager le skill.
